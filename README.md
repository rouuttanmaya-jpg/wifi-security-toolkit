# wifi-security-toolkit
Educational Python toolkit for Wi-Fi security awareness, network diagnostics and authorized Wi-Fi Security Toolkit 🔐

An educational Python toolkit for Wi-Fi security awareness, local network diagnostics, and defensive cybersecurity learning.

Features

* Display local device network information.
* Perform DNS lookups for domain names.
* Estimate password strength locally.
* Provide a practical Wi-Fi security checklist.
* No third-party Python dependencies.

Requirements

* Python 3.9 or newer.

Installation

Clone this repository:

git clone https://github.com/rouuttanmaya-jpg/wifi-security-toolkit.git
cd wifi-security-toolkit

Usage

Run:

python main.py

Follow the interactive menu.

Project Structure

* main.py — Main interactive application.
* wifi_security.py — Local network information and DNS diagnostics.
* password_tools.py — Local password-strength assessment.
* security_checklist.md — Defensive Wi-Fi security recommendations.
* requirements.txt — Dependency information.

Responsible Use

This project is designed for education and authorized defensive use only.

It does not perform Wi-Fi password cracking, unauthorized network access, packet interception, or stealth operations.

Disclaimer

This project is provided for educational purposes. Always obtain authorization before testing or managing a network.
